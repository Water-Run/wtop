# wtop

[English](README.md) · [中文](README-zh.md) · [Français](README-fr.md) · [Русский](README-ru.md)

**WaterRun's top** — системный монитор для терминала, который должен
работать везде: на современных Linux, macOS и Windows, а также на старых
компьютерах и старых консолях, о которых новые инструменты забыли.

Процессор, память, диски, сеть, процессы, GPU и остальное собраны на одном
экране, который подстраивается под размер окна. wtop учитывает и то, что
реально умеет терминал: от truecolor-терминала с мышью до обычного окна
`cmd.exe` совсем без цвета.

```bash
wtop                # интерактивный монитор
wtop --snapshot     # один снимок в JSON, для скриптов
wtop --diagnose     # что wtop видит на этой машине
```

## Поддерживаемые системы

| Система | Состояние |
|---|---|
| Linux (x86_64) | Выпущена версия 0.1.0, ставится через LuaRocks |
| Windows, 32-битная сборка | В разработке. Проверена на Windows Server 2008 и актуальной Windows; собирается под XP |
| macOS (Apple silicon, Intel) | В разработке. Работает на macOS 26 (Apple silicon) |

Сборка для Windows — один 32-битный пакет для всех версий от XP до
Windows 11. Она следит за самой Windows, а не за Linux-прослойкой поверх неё.
XP — цель сборки, но на настоящей машине с XP её пока не проверяли.

> [!NOTE]
> Пока что сборки для Windows и macOS собираются из исходников. Версия
> 0.1.0 и пакет LuaRocks — только для Linux.

## Сделано для старого железа

- **Простые консоли.** Прежде чем включать цвет, мышь, Unicode или
  альтернативный экран, wtop проверяет, что умеет терминал. В консоли без
  поддержки ANSI, например в `cmd.exe` старых Windows, он рисует через
  консольный API Windows, так что сырых escape-последовательностей на экране
  не будет.
- **Маленькие экраны.** Раскладка перестраивается вплоть до очень маленьких
  окон, а бесцветный ASCII-режим с управлением только с клавиатуры остаётся
  удобным.
- **Малая нагрузка.** Данные собираются по таймеру с разумными нижними
  пределами, а невидимые панели не собираются и не рисуются.
- **Без зависимостей.** Только PUC Lua и небольшой модуль на C. Не нужен ни
  Python, ни отдельная среда выполнения, а по умолчанию не запускаются
  никакие внешние программы.

## Что он показывает

- Десять вкладок: Обзор, Процессы, Вычисления, Память, Хранилище, Сеть,
  GPU, Нагрузки, Система и Выводы.
- Список процессов с поиском, сортировкой, деревом и меню сигналов с
  подтверждением.
- Дополнительные глубокие проверки (SMART/NVMe, пропускная способность
  памяти, sshd), если на машине есть нужные утилиты.
- Если показание не удалось получить или оно неполное, это видно по метке
  (например, `denied` или `partial`), а не по пустому полю или нулю.
- Десять языков интерфейса, переключаемых на лету клавишей `L`, и пять
  цветовых тем.

## Установка

### Linux

С LuaRocks 3.13+ и Lua 5.5:

```bash
git clone https://github.com/Water-Run/wtop.git
cd wtop
luarocks --lua-version=5.5 make wtop-scm-1.rockspec
wtop
```

Если LuaRocks не находит Lua 5.5, добавьте `--lua-dir=/путь/к/lua`.

Можно обойтись без LuaRocks и запускать прямо из исходников. Команда
скачает Lua 5.5.1 в репозиторий, проверит SHA-256 и соберёт нативный модуль:

```bash
make run
```

Нужны компилятор C, `make` и `curl` или `wget`.

### Windows

Соберите 32-битный пакет в Linux кросс-компилятором MinGW
(`i686-w64-mingw32-gcc`):

```bash
./tools/build_windows_x86.sh
```

Скопируйте `dist/windows-x86` на машину с Windows и запустите `wtop.cmd`
из `cmd.exe` или PowerShell. В сеансе Cygwin/OpenSSH используйте `wtop.sh`.

### macOS

```bash
make run
```

Сборка появится в `dist/macos/wtop`. Минимальная версия — macOS 11 на
Apple silicon и 10.13 на Intel.

## Использование

| Клавиша | Действие |
|---|---|
| `1`–`8`, `Tab` | Вкладки и фокус |
| `f` | Частота обновления |
| `L` | Язык |
| `?` или `F1` | Все клавиши |
| `q` или `Ctrl+C` | Выход |

<details>
<summary><b>Параметры командной строки</b></summary>

| Параметр | |
|---|---|
| `--snapshot` | Вывести один снимок в JSON и выйти |
| `--agent` | Компактный JSON для скриптов и LLM-агентов |
| `--diagnose` | Показать, какие источники данных работают на этой машине |
| `--lang LOCALE` | Язык интерфейса, например `ru-RU`, `zh-CN`, `fr-FR` |
| `--theme ИМЯ` | `lua-blue`, `water-dark`, `water-light`, `high-contrast`, `colorblind` |
| `--interval МС` | Интервал опроса, от 100 до 10000 (по умолчанию 1000) |
| `--no-color` | Без цвета |
| `--safe-mode` | Не запускать дополнительные вспомогательные программы |
| `--sudo` | Перезапуститься через `sudo` (Linux) |

</details>

Настройки можно также записать в `~/.config/wtop/config.yml`, см.
[config.example.yml](config.example.yml).

### Права root

Для обычного наблюдения хватает прав обычного пользователя. Некоторым
деталям, например соединениям чужих процессов или данным SMART, нужен root:
запустите `sudo wtop` или `wtop --sudo`. Сеанс root не читает и не
записывает ваши личные настройки и раскладку.
